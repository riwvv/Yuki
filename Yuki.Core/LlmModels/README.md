# Модели для Yuki

Положите сюда вашу LLM в формате `.gguf`. 
Например: `Qwythos-9B-Claude-Mythos-5-1M-Q4_K_M.gguf`.
Скачать модель можно на HuggingFace и т.п.


### ВАЖНО!
Не забудьте адаптировать `appsettings.json`, раздел `Host`, пункт `ModelName`.
Так же не забывайте реалистично оценивать свою систему. На этапе разработки использовалась модель из примера выше, работала на RTX 4060, 8GB VRAM, которых хватало с запасом 1-1.5GB.
